Taid downloads weights only after an explicit cutout action. Inference runs on
local CPU. No image bytes, project paths, prompts, or credentials are sent to
the model download host. No API subscription, Python installation, or remote
Python code is required. A 320x320 salient-object model cannot guarantee perfect
pixel-art edges or identify the artist's intended foreground in every image.
Derivatives retain canvas and RGB, multiply existing alpha by model coverage,
preserve the source asset, and are not design/QC-approved automatically.
